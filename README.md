# 体育用品借还管理系统

基于 Flask + SQLite 的课程大作业示例项目，用于管理学校体育用品借用、审核、归还和统计。

## 功能

- 学生注册、登录、退出登录
- 管理员登录和角色权限区分
- 首页统计总库存、可借数量、待审核数量、未归还数量
- 管理员添加、修改、删除、查询体育用品
- 学生按名称和分类查询用品并提交借用申请
- 管理员审核通过或驳回申请
- 管理员确认归还，支持正常/损坏登记
- 学生查看个人借用记录
- 管理员按学生、用品、状态查询全校借用记录
- 超过预计归还日期的记录自动显示为已逾期

## 运行方法

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

访问：http://127.0.0.1:5000

管理员默认账号：

- 用户名：`admin`
- 密码：`admin123`

数据库文件 `sports_borrow.db` 会在首次访问时自动创建，并插入管理员和示例体育用品数据。
